# Contributing to triauth-js

Thank you for your interest in triauth-js. 

* **Issues, reports, and ideas are welcome and wanted.** This is the most useful way to help — see [How to help](#how-to-help) below.
* **Pull requests are not accepted at the moment.** If something needs changing, please open an issue that describes it rather than sending code; an unsolicited pull request may be closed with a pointer to this document.

This model may open up as the library matures beyond beta.

## How to help

Ways to contribute that make a real difference, no code required:

* 🐛 **Report a bug.** Open an issue on the [issue tracker](https://github.com/triauth/triauth-js/issues) with steps to reproduce, the triauth-js version, and your environment (Node.js version or browser).
* 💡 **Request a feature or share feedback.** Open an issue describing the use case. While triauth-js is in beta, its API and behavior are still shaped by what you tell us.
* 📝 **Flag a documentation gap.** If something in the README or the other docs is unclear, incomplete, or wrong, an issue pointing at it is a genuine help.
* ❓ **Ask a question.** If the documentation didn't answer it, your question shows us where the docs need to improve.

> [!IMPORTANT]
> **Do not report a security vulnerabilities in a public issue.**
> If you believe you have found a security vulnerability, follow the private disclosure process in [SECURITY.md](https://github.com/triauth/triauth-js/blob/main/SECURITY.md). 
> For the trust model behind the library, see [triauth.org/protocol/trust-model](https://www.triauth.org/protocol/trust-model).
